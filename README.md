# ⚡ PerpusKuY — Modern TypeScript Digital Library

Sistem manajemen perpustakaan digital berbasis **TypeScript (`src/main.ts`)** & **Interactive Web Dashboard (`index.html`)**.

## ✨ Fitur Utama
- **TypeScript Library Engine (`PerpusKuYEngine`)**: Arsitektur class modular untuk pencarian buku, manajemen stok, peminjaman, dan pengembalian buku.
- **Real-Time Interactive Dashboard**: Pencarian cepat berdasarkan Judul, Penulis, atau ISBN, filter kategori, serta pencatatan transaksi peminjaman & pengembalian mahasiswa.
